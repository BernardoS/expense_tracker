# Expense Tracker

Objetivo do projeto: Controlar os gastos dentro de um orçamento definido pelo usuário

1. O usuário define uma meta de custo (Ex.: 200,00)
2. O usuário define um período (Ex.: 10 dias)
3. O sistema exibe quanto está disponível para o usuário gastar por dia (Ex.:  200,00/10 = 20,00 por dia )
4. O sistema permite você ir cadastrando gastos durante o mês e com base nos gastos cadastrados o limite vai sendo recalculado todos os dias.

## Funcionalidades

- Registra a meta do orçamento
- Registra os gastos diários
- Calcula o gasto diário ideal para o usuário cumprir a meta
- Registra os gastos do dia e os classifica em categorias
